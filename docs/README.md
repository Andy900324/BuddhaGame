## 一、專案總覽

這是一個**單機、離線可玩的互動式修行模擬遊戲**，主題為全真七真之首「**邱長春大仙（邱處機）**」的行誼故事。

玩家扮演少年邱處機，從拜師學道開始，一路經歷王重陽祖師的磨煉、賽麻衣斷「螣蛇鎖口」餓死之相、蟠溪六年苦行，直到「捨己從人」通過三官大帝考驗、圓滿成仙。

- **呈現形式**：純 HTML＋CSS＋JavaScript，**單一檔案、全部資源內嵌**（插圖為內嵌 SVG 水墨簡筆，無外部圖片／字型／連線需求）。
- **素材來源**：`邱長春大仙行誼-20221019_林瑋揚.pptx`（38 頁講義）與《七真史傳》（taolibrary.com 全文），見遊戲腳本檔開頭。
- **創作階段**：腳本 v1 已定稿；互動 HTML 已完成全部流程（10 個事件＋2 個討論＋1 個敘事＋特殊事件＋6 段結局＋回向＋結語）。

## 三、遊戲內容與架構

### 3-1 核心概念：命運 vs 運命

> 「命也，不可改；運也，可以轉。」
> 沒有修行的人被「命」所「運」；修行者能「運」用有限的生命，這就叫「運命」。

### 3-2 數值系統

| 數值 | 初始 | 上限 | 判定 |
|---|---|---|---|
| 意志力 | 70% | 100% | 低於 20% → 道心破裂，**模擬失敗** |
| 修道心 | 10% | 100% | 降至 10% 以下 → **模擬失敗**（魔障期間例外） |
| 修行進度 | 0% | 100% | 達 100% 且三項俱滿才可通過特殊事件 |

隱藏數值：**大餓**（72 次圓滿）、**小餓**（計數）、**慈心**（影響特殊事件）、**魔障**（第二章入魔期間鎖定修道心）。

### 3-3 章節與流程

HTML 中實作的章節結構（與腳本的四章略有重新編排）：

| 章節 | 內容 | 流程 ID |
|---|---|---|
| 第一章　學道拜師 | ev1 祖師的反應 → ev2 祖師不收徒 → ev3 門外聽法 → ev4 賜號長春 | `ev1`~`ev4` |
| 第二章　麻衣論相 | ev5 師父南遊 → **討論一** → **敘事（師父羽化遺言）** → ev6 螣蛇鎖口 | `ev5` `talk1` `story1` `ev6` |
| 第三章　相隨心變 | ev7 溪邊仙桃 → ev8 秦嶺強盜 → ev9 鐵鍊鎖樹 → **討論二** → ev10 蟠溪六年 | `ev7`~`ev10` `talk2` |
| 第四章　天仙狀元 | **特殊事件：捨己從人**（三官大帝）→ 六段結局 → 回向 → 結語 | `FLOW` 之後 |

完整流程順序（`FLOW` 常數）：`ev1 → ev2 → ev3 → ev4 → ev5 → talk1 → story1 → ev6 → ev7 → ev8 → ev9 → talk2 → ev10`，ev10 之後進入特殊事件。

### 3-4 失敗與重試

- 失敗判定：意志力 < 20%／修道心 ≤ 10%／選到 ❌ 選項／特性一「命苦之人」觸發直接失敗。
- 重試方式：**回到該章開頭重新選擇**（非整局重來），數值回復到該章開始時的存檔點（`snapshot()`／`restore()`）。
- 每章存檔點：第二章開始時、第三章開始時。

### 特色功能

- **單檔離線**：無任何外部資源請求，拷貝即用。
- **特性機制**：特性一「命苦之人」——選對仍可能觸發壞情況（30% 機率；其中 30% 直接失敗、70% 扣 10% 意志力）。
- **PPT 匯出**：可一鍵下載含全部講義內容的 `.pptx`，適合講道場合直接使用。
- **程式檔頭註解**：檔案開頭說明四章架構（見主 HTML 193–199 行）。
